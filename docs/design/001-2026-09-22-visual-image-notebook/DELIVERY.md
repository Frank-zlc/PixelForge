# 整改任务与阶段验收

[返回总方案](README.md)。用户已指示开始分阶段开发，N1 已完成基础能力验收；N2—N5 尚未开始。阶段编号 N0—N5 与历史 Android 产品阶段 P0—P9 区分。

## 1. 整改主线

| 发现的问题 | 处理措施 | 对应需求/阶段 | 验收证据 |
| --- | --- | --- | --- |
| 目录只记录默认参数、单效果图和手工状态 | 版本化工具 schema、多个例子、实际依赖探测，旧 ID 迁移 | R01 / N1 | 目录与同版本真实输出一致；状态能解释不可用原因 |
| 浏览器文件/目录与 Blob URL 无法恢复 | 显式导入托管素材、记录相对路径/哈希、缩略图和引用 | R02 / N1 | 导入同名文件并重启后仍可区分和打开 |
| 现有算法返回单一 PNG | 具名端口、类型校验和多结果展示 | R03、R05 / N1—N3 | mask、OCR 文字框、匹配分数能独立查看 |
| 多步骤不能连接、保存或重跑 | 实验本与步骤、输入引用、快照执行、过期传播 | R03、R04 / N2 | 代表性处理链保存、重开、改上游并重跑 |
| OCR、模板、差异只在设备脚本有入口 | 离线输入适配与第二输入、结构化输出 | R05 / N3 | 不连接设备完成识别/匹配/差异流程 |
| 旧算法与设备/固定像素耦合 | 抽取纯算法，修正颜色/坐标/边界问题，样图评估 | R07 / N5 | 正负样图、非零 ROI、多分辨率回归 |
| 原架构文档与实现不一致 | 每阶段按代码现状修正文档和使用说明 | R08 / 全阶段 | 文档链接、状态、示例和真实实现一致 |

### N2：可保存的图形化实验本

- [ ] 新建/保存/重开实验本，步骤增删改排、说明单元、基于 schema 的参数面板。
- [ ] 素材或前序具名端口作为输入；拒绝类型不兼容、前向引用和非法重排。
- [ ] ROI 像素坐标、连续裁剪变换、缩放/平移预览、原图与结果并排查看。
- [ ] 运行快照、历史、多种输出、失效传播、缓存来源、失败与中断状态。
- [ ] 乐观锁、幂等提交、单本单活动运行、进程取消/超时与服务重启恢复。
- [ ] 修复旧请求晚到覆盖当前预览的问题；切换输入或参数后只显示对应 run 的结果。

退出条件：两张同名图片可区分；裁剪 → 颜色提取 → 二值化可串联；修改裁剪后下游过期；保存、刷新和服务重启后输入、参数、ROI、结果和两次历史均恢复；取消不遗留运行进程。

### N3：离线识别与比较

- [ ] 模板匹配：双图输入、可选 mask、ROI、多尺度、分数和候选框覆盖层。
- [ ] OCR：语言包/引擎诊断、可选 ROI、完整文字、词框、置信度、空结果语义。
- [ ] 双图差异：尺寸/对齐规则、差异比例、可视化与解释；先复用现有 `diff_ratio`。
- [ ] 目录页示例与工具版本更新，新增正例、负例、非零 ROI 与缺依赖测试。

退出条件：不连接设备，在实验本中分别完成 OCR、模板匹配和差异流程；文字、位置、分数、输入哈希和工具版本均可从历史追溯。N1—N3 共同组成建议首版交付。

### N4：流程复用与批量

- [ ] 实验本复制/模板化；目录批量应用同一发布版本流程，逐文件结果和失败报告。
- [ ] 实验与结果导入导出，清单和 SHA-256 校验，路径不依赖原电脑。
- [ ] 设备无损截图经用户操作保存为素材并打开实验本，关联项目但独立保存。
- [ ] 明确 batch、snapshot 等工作流能力的目录统计方式，补容量控制与清理 UI。
- [ ] 定义实验工具链到设备 Step 的逐项映射、输入来源、版本与不支持项，再实现导出。

退出条件：一次配置可对目录多图批量运行；部分失败不丢其他结果；导出后能验证完整性；设备截图成为冻结素材可离线重跑。

### N5：MHXY 算法深化

- [ ] 用固定样图集逐项评估 [MHXY 复用清单](MHXY_REUSE.md)；先建立旧版/当前版基线。
- [ ] 重构 HSV 范围、形态学和文字候选区域，输出 mask、候选框与过滤原因。
- [ ] 对模板二次校验和附近查找进行正负例、误报、漏报与耗时对比；无改善则保持可选或不发布。
- [ ] 每个发布工具配版本、参数说明、示例、兼容测试和适用边界；更新功能目录可用数量。

退出条件：每个新增工具在登记样图、异常输入、非零 ROI 和不同分辨率下有可复查证据；不能仅凭肉眼效果图宣称准确率改善。

## 3. 核心验收矩阵

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 离线完整链 | 导入 → 裁剪 → 颜色筛选的 `mask` → 二值化 → OCR | 每步有类型明确的中间结果；OCR 文字/框与图像坐标一致 |
| 上游修改 | 改裁剪 ROI，再查看后续结果并重跑 | 下游显示过期，历史保留；新运行引用新输入哈希 |
| 保存恢复 | 保存后刷新浏览器及重启服务 | 素材、参数、ROI、步骤顺序、运行历史和结果仍可打开 |
| 双图匹配 | 选择搜索图和模板图，限定非零 ROI | 分数、匹配框、全图坐标正确；模板图不能隐式使用第一张图 |
| 目录重名 | 两个目录各导入 `a.png`，再重试其中一张 | 素材身份与路径清晰，无静默覆盖或混淆 |
| 取消/超时 | 运行耗时算法后取消或触发限制 | 实际工作进程退出，终态准确，可重试，不发布半成品 |
| 版本/依赖 | 旧版本实现缺失、无 OCR 语言包 | 历史能读，重跑给出升级/安装说明，其他工具可运行 |
| 文档与目录 | 对照代码版本和工具效果例 | 可用数量、函数名、示例结果与实际状态一致 |

每条验收记录应填写提交、环境、输入素材哈希、运行 ID 或测试名、实际结果、失败原因。上表是目标，不是已通过报告。

## 4. 风险与处理

| 风险 | 处理方案 |
| --- | --- |
| 旧目录 startup UPSERT 覆盖扩展数据 | 显式迁移、字段所有权分开、旧 ID 回归；迁移前一致性备份 |
| 图片与结果占满磁盘 | 导入限额、用量提示、引用保护和可审核清理；N1 实测后定默认值 |
| OCR/图像计算阻塞或退出不净 | 受控子进程、超时与取消确认、重启恢复；相关故障用例作为阶段门槛 |
| ROI/EXIF/裁剪坐标错位 | 标准化预览与解码、局部坐标和父图变换记录、边界与非零 ROI 样例 |
| MHXY 参数只适用旧游戏截图 | 扩展样图、比较正负例和分辨率；不复制固定路径、分辨率或未经验证的阈值 |
| 文档与代码再次分叉 | 每期同步总方案、子文档、功能目录说明和实际验收证据 |

### N1 验证环境与限制

- 验证环境：本地 macOS、Python 3.13、OpenCV 5.0、FastAPI 0.141；测试用临时数据目录，无设备连接。完整后端测试包含模拟设备协议，**不代表真机验收**。
- 真实图片准确率尚未评估；目前合成图及已知色块用于契约和回归，MHXY 正负样图与人工标注留到 N5。demo 哈希只保证版本效果未悄悄变化。
- N1 目录导入在浏览器逐文件提交，可看到成功/失败汇总；一次批次上限 500 张/512 MB。批量运行不是 N1 功能。
- 自动化验证覆盖不同相对目录下的同名图片及服务重启后的读取；浏览器实际操作验证了单张导入到灰度结果。整目录的浏览器操作尚未做自动化端到端测试。
- 实验本、步骤保存、运行历史、取消/超时和设备截图入库仍未实现，分别在 N2—N4 交付。
- 全仓库 Ruff 检查仍报告既有文件中的 67 条问题；N1 新增/修改的目标代码通过定向 Ruff 和 MyPy。后续整理旧代码时单独处理，避免把无关清理混入 N1。
