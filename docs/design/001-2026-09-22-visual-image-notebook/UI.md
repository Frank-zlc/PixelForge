# 页面布局与交互设计

[返回总方案](README.md)。功能目录、工具详情和素材库的 N1 页面已开始实现；实验本及运行详情仍是 N2 设计，以 [交付记录](DELIVERY.md) 为准。

## 1. 菜单和页面

| 一级菜单 | 页面与拟定路径 | 核心内容 |
| --- | --- | --- |
| 实验本 | `/app/notebooks.html` | 新建、搜索、最近修改、关联项目、复制、归档 |
| 实验本详情 | `/app/notebook.html?id=…` | 素材、步骤单元、参数、结果、历史 |
| 功能目录 | 保留 `/app/tools.html` | 类别筛选、关键词、可用状态、示例效果、数量统计 |
| 工具详情 | `/app/tool.html?id=…&version=…` | 介绍、输入输出、参数、函数名、示例、添加到实验本 |
| 素材库 | `/app/assets.html` | 图片/目录导入、分组、缩略图、尺寸、来源、使用情况 |
| 设备工作台 | 保留 `/app/index.html` | 原有连接、投屏、取材、脚本与调试；N4 增加送入实验本 |
| 运行详情 | `/app/run.html?id=…` | 快照、步骤状态、结果、错误、耗时、导出 |

运行详情从实验本的历史侧栏进入，无需再占一级菜单。依赖诊断和存储用量先放右上角设置入口。首版保持当前根路径默认打开设备工作台，新增统一导航直达实验本。

## 2. 功能目录与工具详情

目录顶部显示“可运行算法 / 待接入算法 / 缺少依赖 / 规划算法”，统计以当前环境实际状态为准；批量、导出等工作流能力单独显示，避免把页面功能算成算法数量。

每张工具卡展示：类别、名称、简述、处理前后缩略图、状态、推荐用途。支持搜索名称/说明/函数名、类别筛选和“只看可运行”。可用项提供“快速体验”和“加入实验本”；待接入或规划项可以查看详情和计划阶段。

详情页信息：

- 基本信息：稳定 ID、类别、功能介绍、实现函数名、来源、当前版本。
- 输入/输出：支持的图片类型、是否需要第二张图、是否支持 ROI、可能产生的文本或标注。
- 参数：中文说明、默认值、范围、枚举、单位；由工具参数定义生成表单。
- 示例：原图、参数、结果图/掩码/文字、版本和运行记录；一个工具可有多个适用场景和失败边界示例。
- 可用状态：例如“缺少中文语言包”，给出本项目诊断入口。

示例使用和实际执行采用同一工具版本。参数调整后快速体验生成临时实验草稿；点击保存后可在实验本中继续，避免维护第二套处理引擎。

桌面优先；窗口较窄时两侧面板折叠为抽屉。图片、参数和运行按钮保持可见。说明单元支持文本说明，不执行代码。

### 单元操作

- 每个工具单元都有名称、版本、输入引用、参数摘要、运行状态、输出预览。
- 新增单元默认连接前一单元兼容的主输出；没有兼容输出时要求选择输入，不能把 OCR 文本当图片自动传递。
- 输入下拉框展示素材及前序单元的具名输出：如“步骤 2 / mask”。模板匹配同时选择“待查图片”和“模板图片”。
- 支持复制、折叠、删除和重排。删除有下游引用时列出受影响单元，需先改引用；重排造成前向引用时拒绝并解释原因。
- 运行操作为“当前步骤”“运行到此”“运行全部”“从此重跑”，语义以 [执行规则](API_EXECUTION.md) 为准。自动补跑的前置步骤在提交前列明。
- 图像结果支持适应窗口、100% 像素、缩放、平移、并排对比；掩码用独立标签展示，检测框可开关；文本可复制，表格可查看。

### ROI 与坐标

框选基于当前输入图，显示 x、y、width、height，支持数值调整和清除。缩放和平移只改变显示，保存的始终是输入图的整数像素坐标。切换输入后清除不再适用的选区并要求重新确认。

裁剪后的图片有自己的局部坐标，界面可以切换查看映射到原图的位置；算法输出需标明所属图片，不能把局部坐标直接画到原图上。裁剪边界和坐标变换详见数据模型。

## 4. 导入与保存

1. 用户选择文件或目录，页面先列出文件数量、总大小、相对路径及不支持项。
2. 点击“导入”后复制到托管素材库。显示逐文件结果，失败项可重试；同名文件以相对目录和 ID 区分。
3. 预览、ROI 和算法都使用服务端标准化后的图片，保证 EXIF 旋转后坐标一致。
4. 原文件保留；处理结果另存，不覆盖原图。浏览器选目录不等于服务端获得任意本地目录访问权限。
5. 实验草稿自动保存，提供明确“已保存/保存中/保存失败”状态。运行前先保存成功；离开页面存在未保存内容时提醒。多标签修改冲突要求重新加载或另存副本。

原始图片、输入引用、参数、ROI、结果与运行记录由后端保存。刷新页面或服务重启后能恢复已保存实验；临时浏览器 URL 不作为恢复依据。

## 5. 状态与错误展示

| 场景 | 页面行为 |
| --- | --- |
| 没有素材/步骤 | 展示导入/添加工具入口和可加载示例 |
| 已有结果后改参数或输入 | 保留旧结果，标“结果已过期”，列出受影响后续步骤 |
| 运行中继续编辑 | 显示“本次运行使用 revision N”；新草稿结果需另行运行 |
| 工具缺依赖/版本缺失 | 显示具体原因；历史可查看，重跑前安装依赖或显式升级 |
| OCR 未识别到文字/模板未匹配 | 运行成功，显示空结果/未找到及可用分数 |
| 算法失败/超时 | 错误放在对应单元，依赖步骤标“受阻”；保留其他已成功结果 |
| 用户取消 | 显示“正在停止”；后端确认进程已退出后显示“已取消” |
| 服务重启遇到运行中任务 | 标“已中断”，允许用户重新运行 |
| 切换图片时旧请求完成 | 结果只归属原 run/step，不覆盖当前图片或新草稿 |
| 删除素材被引用 | 列出实验/历史/模板引用，阻止直接物理删除 |

## 6. 代表性验收流程

导入目录 → 选择图片 → 裁剪 → 颜色提取 → 选择 mask 输出 → 二值化 → OCR → 查看文字框 → 改裁剪区 → 后续结果标过期 → 运行到 OCR → 保存 → 刷新并重启服务 → 重开并查看两次运行差异。

另用两张图片验证模板输入、匹配分数和原图坐标，用缺少 OCR 依赖的环境验证可用性提示。完整测试矩阵见 [开发与验收](DELIVERY.md)。
