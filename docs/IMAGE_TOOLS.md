# 图片工具目录

当前入口：`/app/tools.html` 功能目录与单步预览，`/app/tool.html?id=crop` 工具详情，`/app/assets.html` 托管素材库。目录将 6 项可运行算法、3 项待接入算法、2 项规划算法与 1 项规划工作流分别统计。实验本页面和多步历史仍在 N2 计划中。

打开 `/app/tools.html`，可以查看功能目录、效果图和状态。页面支持打开单张图片或浏览器选定的图片目录；点击文件后在原图上拖动框选，选择工具运行，预览并下载 PNG。处理图片不需要设备会话。

功能目录存储在 `PIXELFORGE_DATA_DIR/image_tools.sqlite3`。`image_tools` 保存稳定 ID、类别、函数名、介绍、状态及当前版本等目录投影；`tool_versions` 保存参数/端口契约与代码哈希，`tool_examples` 保存对应版本的示例和输出引用。可运行状态由内置算子注册、依赖探测和示例生成结果派生；页面只允许运行 `available` 的工具。示例图片由相同版本的处理函数生成，不把手填路径当作效果证据。

当前内置算子定义在 `image_lab/operators.py`，旧单步处理仍由 `vision/tool_catalog.py` 适配。服务启动时将内置定义同步到 SQLite；数据库负责查询、展示和保留版本，客户端提供的函数名永远不会直接执行。新增工具时需要注册处理函数与参数/端口契约，并增加人工标注的正负样图验证。

前端选定的目录由浏览器提供 `File` 列表及相对路径，并非持久目录句柄；服务端无法直接读取用户电脑的任意路径。只有点击运行时，当前图片字节才会发给 `/api/image-tools/{id}/run`；服务端限制上传大小为 20 MB、解码后为 3000 万像素。结果直接返回浏览器，不自动写入项目目录。刷新页面后需要重新选择图片。

在素材库中选文件或目录并点击“导入所选图片”，才会复制原图到 `PIXELFORGE_DATA_DIR/image_lab/`。素材库保留原图和标准化 PNG 预览，记录相对路径、SHA-256、尺寸和导入批次；同名图片可并存。透明图片预览以白底合成，JPEG 的 EXIF 方向在预览解码时应用。素材列表在刷新或服务重启后仍可查看。单批最多 500 张、512 MB；每张沿用 20 MB/3000 万像素限制。

N1 新接口位于 `/api/image-lab`：`/tools` 查看版本/参数/端口及可用状态，`/tools/{id}/examples` 查看持久示例，`/tools/{id}/run` 返回具名输出（颜色提取含 `image` 与真正的单通道 `mask`），`/imports` 和 `/assets` 管理导入。旧 `/api/image-tools` 保持兼容；实验运行及历史将在 N2 接入。

多步骤实验本、运行历史及离线 OCR/匹配的分阶段开发方案见 [PF-DES-001](design/001-2026-09-22-visual-image-notebook/README.md)。以该方案的实施记录判断新增能力是否已交付。
